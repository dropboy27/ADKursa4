# Codebook: разметка эмоциональной окраски русскоязычных текстов

**Проект:** Сравнительный анализ влияния ручного и искусственного обогащения данных на качество и устойчивость обучения моделей машинного обучения.

**Датасет:** CEDR v1

## 1. Цель разметки

Целью является определение эмоций, выраженных в русскоязычных текстах, собранных из разных источников.

Разметка выполняется в соответствии с классами исходного датасета CEDR для последующего обучения моделей многометочной классификации.

## 2. Единица разметки

Единицей разметки является отдельное высказывание: предложение или короткий самостоятельный пост.

Каждый текст может получить несколько эмоциональных меток либо пустой набор меток.

## 3. Описание классов

| ID | Класс | Условия присвоения |
|---|---|---|
| 0 | Joy | Радость, счастье, удовольствие, восторг, позитивное эмоциональное переживание |
| 1 | Sadness | Грусть, печаль, тоска, сожаление, эмоциональное разочарование |
| 2 | Surprise | Удивление, изумление, неожиданность произошедшего |
| 3 | Fear | Страх, тревога, испуг, опасение нежелательных последствий |
| 4 | Anger | Злость, раздражение, гнев, возмущение |

Отсутствие выраженной эмоции обозначается пустым набором меток `[]`.

## 4. Общие правила разметки

**Правило 1.** Метки присваиваются по смыслу высказывания, а не только по отдельным словам.

**Правило 2.** Допускается присвоение нескольких меток, если в тексте выражены несколько эмоций.

**Правило 3.** Если в тексте невозможно определить ни одну из пяти эмоций, аннотатор должен указать пустой набор меток.

**Правило 4.** Эмодзи, пунктуация и стилистика могут использоваться как дополнительные признаки.

**Правило 5.** При разметке необходимо учитывать отрицания, иронию и сарказм. Например, наличие слова «рад» не всегда означает выражение радости.

**Правило 6.** Неоднозначные случаи отмечаются для последующего обсуждения.

**Правило 7.** Не допускается додумывание отсутствующего контекста и угадывание эмоции.

## 5. Примеры разметки

| Текст | Метки | Причина |
|---|---|---|
| Как же я счастлив сегодня! | `[0]` | Явная радость |
| Скучаю по старым друзьям | `[1]` | Грусть, тоска |
| Ничего себе, я такого не ожидал! | `[2]` | Удивление |
| Боюсь, что завтра всё пойдёт не так | `[3]` | Страх и тревога |
| Меня ужасно раздражает это поведение | `[4]` | Раздражение |
| Я рад, но немного боюсь | `[0, 3]` | Радость и страх |
| Сегодня открылся новый магазин | `[]` | Эмоция не выражена |
| Я совсем не боюсь экзамена | `[]` | Страх отрицается, другие эмоции не выражены |

Примеры являются иллюстративными и должны быть проверены в ходе пилотной разметки.

## 6. Процедура разметки

Каждый текст независимо размечается двумя аннотаторами по единому Codebook.

До завершения независимой разметки участники не просматривают решения друг друга.

Для каждого текста фиксируются:

- Идентификатор текста.
- Идентификатор аннотатора.
- Выбранные метки.
- Время, затраченное на разметку.
- Комментарий при необходимости.

Разметка выполняется с помощью специализированного инструмента, например Label Studio.

## 7. Разрешение разногласий

После завершения независимой разметки результаты сравниваются.

Для оценки согласованности аннотаторов рассчитываются Percentage Agreement и Cohen's Kappa отдельно по каждому эмоциональному классу.

В случае разногласий участники обсуждают спорный текст с опорой на Codebook.

После обсуждения фиксируется итоговый согласованный набор меток. Первоначальные метки обоих аннотаторов сохраняются для оценки качества разметки.

## 8. Контроль качества

Перед основной разметкой проводится предварительная проверка Codebook на 15–20 текстах.

По результатам проверки анализируются разногласия и при необходимости корректируются правила разметки.

После утверждения правил проводится пилотная разметка не менее 50 объектов.

Основная разметка выполняется по согласованной версии Codebook.
